# Assemble: examples

- **A course lesson:** voice plus one window, 4K, a zoom on a small side panel.
- **A two-sided demo:** an admin and a user side by side in the browser frame, with the address
  pill showing your product's domain (`frame.address`).
- **Silent B-roll** of a website for a video editor: no voice, `transition.kind` set to a plain
  fade, exported at 1080p (`output.width: 1920`).
