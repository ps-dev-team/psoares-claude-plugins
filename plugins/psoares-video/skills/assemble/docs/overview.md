# Assemble: the finished video

Turns the recordings from `screen` (and the voice, if there is one) into a video ready to
publish.

- **A large, sharp pointer** in the style of Screen Studio, gliding on its spring, squeezing on
  each click. Bring Screen Studio's own cursor set for the exact look, or use the plain one.
- **Smooth zooms** where a beat asked for one, never past the window's edge.
- **One window full frame, or two** side by side in a plain browser frame with a soft shadow.
- **Fades** between scenes.
- **The voice** under the picture.
- **4K at 60 fps**, or any size in the config. A quick draft first, with a review page where you
  can leave comments pinned to moments.
