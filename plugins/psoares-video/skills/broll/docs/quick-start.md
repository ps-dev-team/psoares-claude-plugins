# B-roll: quick start

1. Install and sign in to the Higgsfield CLI: `npm i -g @higgsfield/cli`, then
   `higgsfield auth login`.
2. Put the photos in `faces/src/`.
3. Ask Claude: "Make listening and talking clips of these two people for a video call." Claude
   gives you the total in credits before spending anything.
4. For a call scene, the `screen` skill plays the feeds as each account's camera.
