# human-prose

## Purpose

Write any content text (articles, scripts, posts, emails) that sounds naturally human. Avoid AI writing patterns.

## When to Use

Apply when writing or editing content that will be read by humans and shouldn't feel AI-generated.

## Language

Infer from user communication. Default to English if unclear.

## Anti-Patterns to Avoid

### Structure
- No "In today's [X]..." openers
- No "Let's dive in" / "Let's explore"
- No "In conclusion" / "To summarize"
- No "Remember:" followed by recap
- No numbered lists for everything
- No perfect parallel structure in every list

### Word Choice
- No "crucial" / "essential" / "vital" / "key" overuse
- No "leverage" / "utilize" (use "use")
- No "robust" / "comprehensive" / "cutting-edge"
- No "harness the power of"
- No "at the end of the day"
- No "it's worth noting that"

### Tone
- No excessive hedging ("It's important to note that...")
- No sycophantic openers ("Great question!")
- No over-explanation of obvious things
- No fake enthusiasm with exclamation marks

### Flow
- Vary sentence length (short punchy + longer flowing)
- Use contractions naturally
- Allow imperfect transitions
- Let ideas breathe without constant signposting

## What Good Prose Looks Like

- Sounds like a real person wrote it
- Has rhythm and variation
- Gets to the point
- Uses specific examples over generic statements
- Has personality and occasional imperfection
- Matches the context (casual for posts, tighter for scripts)

## Integration

This skill should be active whenever the agent produces content text. It's not invoked explicitly — it's a lens applied to all writing tasks.

## Notes

- Don't overcorrect into robotic simplicity
- Some "AI patterns" are fine in moderation — the problem is accumulation
- Match the user's voice if examples are provided
